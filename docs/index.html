privacy and proof

Known patterns. Clear limits.

Builtins scrub private keys, common token shapes, email, Bearer and Basic auth, URL login and secret assignments. Add private org names, hosts and tickets to local policy.

AcmeCorp => internal-org
registry.acme.internal => internal-registry
re:PROJ-\d+ => <ticket>

Keep rules at ~/.claude/.journal-redact, outside Git. Missing policy uses builtins only. Invalid, unreadable or residual matching rules block flow. Public publish needs policy file.

Pattern scan cannot prove prose private. Model and Git traffic leave machine. Review summaries for business facts and names. Access controls on read site do not protect model or Git traffic.

questions

Asked often.

Which agents can record work?
Claude and Codex use transcript hooks. Cursor and Gemini use documented hook text. Copilot and other agents send manual summary through shared skill or stdin JSON.
Does capture wait for model?
Native hooks spawn detached writer. No fixed timing guarantee. Root lock spans save and sync; busy writer exits with retry notice.
What does APM install?
Manual skill plus core for chosen targets. Native hooks still need reviewed direct installer. APM does not normalize transcript schemas or activate universal hooks.
Where do entries live?
Private Markdown repo, default ~/claude-journal, grouped by project. Point recorder at private clone with existing origin branch. Optional Obsidian vault uses same files.
What if model or sync fails?
Failed model skips entry. No raw fallback. Failed sync keeps local Markdown, returns failure and leaves dedup marker unchanged. Manual retry may create second entry; inspect local state first.
