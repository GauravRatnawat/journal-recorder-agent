Your AI coding sessions,
journaled while you sleep.

Every Claude Code and Codex session becomes a rich markdown journal entry — commands run, files touched, decisions made. Sorted per project, indexed, committed, and pushed to your private GitHub. You never lift a finger.

Install in 2 minutes View source →
~/my-repo — claude
How it works

Hooks in front. Writer out back.

01

Turn ends

Claude's Stop hook, a /compact, or Codex's notify fires. The fast path checks the per-project dedup marker and substance — exits in under a second. Your session never waits.

02

Full extraction

The whole transcript — messages plus tool calls: every shell command, every file edit. Long sessions keep head + tail, middle elided at a 40k budget.

03

Detached writer

A background process writes the entry via claude -p on Haiku, updates INDEX.md, commits, and pushes to your remote. Survives you closing the terminal.

Features

Everything captured. Nothing lost.

✓Real commands, real files

Tool calls feed the writer, so "Commands Run" and "Files Modified" sections are extracted, not hallucinated.

✓Per-project folders

Each repo gets its own subfolder, its own INDEX.md, its own 30-minute dedup marker. Parallel projects never block each other.

✓Claude Code + Codex

One engine, both tools. Same project, same window → one entry, whichever finishes first. Codex rollouts parsed natively.

✓Auto-push to GitHub

Journal root is a git repo. Every entry commits and pushes to your private remote. Offline? Next push carries the backlog.

✓Never silent, never lost

Every run logs one line to .journal.log. If generation fails — token limits, rate limits, timeouts — a fallback entry with the raw session digest is written instead.

✓Frontmatter + weekly digests

YAML frontmatter on every entry — Obsidian-friendly. journal.py digest --days 7 rolls the week into one page.

The output

Entries a stranger could pick up cold.

Written for a reader with zero context. Exact paths, verbatim commands, the why behind each decision.

Install

Two minutes, three curls.

1 — Engine + hooks

mkdir -p ~/.claude/hooks
curl -o ~/.claude/hooks/journal.py \
  https://raw.githubusercontent.com/GauravRatnawat/journal-recorder-agent/main/journal.py
curl -o ~/.claude/hooks/post-stop-journal.sh \
  https://raw.githubusercontent.com/GauravRatnawat/journal-recorder-agent/main/post-stop-journal.sh
curl -o ~/.claude/hooks/post-compact-journal.sh \
  https://raw.githubusercontent.com/GauravRatnawat/journal-recorder-agent/main/post-compact-journal.sh
chmod +x ~/.claude/hooks/post-*.sh

Then wire Stop + PostCompact hooks in ~/.claude/settings.json — exact JSON in the README.

2 — GitHub sync (optional, one command)

cd "$(python3 ~/.claude/hooks/journal.py resolve-dir)"
gh repo create claude-journal --private --source . --push

Every entry after this pushes itself.

3 — Codex (optional)

curl -o ~/.claude/hooks/codex-notify.sh \
  https://raw.githubusercontent.com/GauravRatnawat/journal-recorder-agent/main/codex-notify.sh
chmod +x ~/.claude/hooks/codex-notify.sh
# ~/.codex/config.toml
notify = ["/Users/<you>/.claude/hooks/codex-notify.sh"]

Requirements: Claude Code + Python 3. That's the whole stack — no daemons, no databases, no dependencies.
